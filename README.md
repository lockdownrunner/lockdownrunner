> Build a simple web application using HTML, CSS, and JavaScript (or optionally use a framework like React) where patients can:

1. View available hospital resources (e.g., doctors, beds, departments).


2. Fill out a booking form with their name, symptoms, and preferred time.


3. Submit the form to reserve resources before arriving at the hospital.


4. Send a notification to the doctor or hospital staff about the booking.



The design should be clean and responsive. Use mock data for available resources and simulate the booking system using JavaScript only (no backend for now). Include confirmation feedback after submission.
